# Локальные ресурсы учебного примера

В репозиторий входят код подключения и описание зависимостей. Меши, анимации,
текстуры, звук, Niagara и созданные на их основе локальные ресурсы в Git не входят.
У ресурсов свои условия использования: лицензия кода DasForUE на них не распространяется.

Текущий профиль повторяет **UE5.6-CourseProject**, commit
`992f860922373d50db05eacc5e1fce952ed88c13`: Manny Simple с перенесёнными анимациями
Gideon, монтаж основной атаки и, по выбору, эффекты/звуки курса. Это отличается от
сырого пакета Paragon Gideon: один пакет с Fab не содержит готовые Manny-retargeted
анимации из этой ветки. Исходный C++ RogueAnimInstance не требуется: локальный
генератор создаёт отдельный AnimGraph для locomotion и montage slot.

Источники и условия:

- [Описание ресурсов и авторы курса](https://github.com/tomlooman/ActionRoguelike/blob/UE5.6-CourseProject/README.md).
- [Официальный Paragon: Gideon от Epic](https://www.fab.com/listings/51935254-f70f-400a-8ca5-91a3e1b83e3b).
- [Epic Content License Agreement](https://www.unrealengine.com/eula/content).
- Niagara-конвертации: tharlevfx. Аудио: Sander van Zanten. Их включение в публичную
  раздачу требует отдельного уточнения; данный механизм оставляет файлы локально.

## Установка

Для перехода к официальному источнику и инструкции автора:

```powershell
python Scripts/setup_external_assets.py --open-sources
```

Если у вас уже есть ресурсы учебной ветки, установите их из её папки Content:

```powershell
python Scripts/setup_external_assets.py --source-content C:/path/to/ActionRoguelike/Content
```

Для локального использования ресурсов, опубликованных самим автором, можно
загрузить закреплённую версию прямо из его публичного Git-репозитория:

```powershell
python Scripts/fetch_course_assets.py
```

Это загрузка из источника автора, а не обход Fab/аккаунта Epic. Она не выдаёт
лицензию на контент и не принимает соглашения за пользователя. Для получения
пакетов через Epic используйте свой аккаунт и официальный Fab/Launcher.

Флаг `--with-course-effects` у обеих команд добавляет Niagara и звуки курса.
Выбранные звуковые волны используются напрямую: сложные MetaSound-микшеры курса
не нужны. Полёт использует зацикленную исходную волну. Без этого флага доступны
модель и анимации, а графику эффектов можно назначить отдельно в локальном профиле.

После установки вне PIE выполните в Unreal Python:

```python
import runpy
runpy.run_path(r'C:/src/ActionRoguelikeDas/Scripts/prepare_external_assets.py')
runpy.run_path(r'C:/src/ActionRoguelikeDas/Scripts/prepare_character.py')
```

Пути переносимы: скрипты определяют проект через своё расположение. Пример выше
показывает путь текущей локальной установки. Для анимаций в редакторе обязательны плагины `AnimationData` и `ControlRig`,
уже включённые в проекте. Перед загрузкой анимаций проверяется наличие их классов:
без AnimationData Unreal не может восстановить DataModel анимации.
Нужна собранная версия DasForUE с
`DasAssetLibrary` и `DasAnimationAssetLibrary`.

## Что создаётся

- `Content/DasRogueExternal/DA_Presentation`: локальные настройки ресурсов.
- `Content/DasRogueExternal/ABP_Locomotion`: простой граф движения и слота montage,
  без исходного C++-родителя. Расчёт движения и игровой логики остаётся в daScript;
  граф отображает скорость/направление персонажа.
- `Saved/ExternalAssets/install.json`: список установленных файлов и SHA-256.
- `Saved/ExternalAssets/prepared.json`: результат настройки Unreal.

Исходные папки сохраняют оригинальные имена `/Game/...`, чтобы ссылки материалов
и анимаций не ломались. Все эти внешние папки и `DasRogueExternal` исключены через
`.gitignore`. Локальные изменения чужих ресурсов также остаются вне публичного Git.

В Class Defaults персонажа `UseExternalPresentation` включает локальный профиль.
При отсутствии профиля остаётся конус и штатные эффекты движка. Игровой код и
общие Blueprint примера не должны содержать жёстких ссылок на локальные ресурсы.

Скрипт установки копирует только граф зависимостей выбранных ресурсов. Он не
переносит исходный игровой Blueprint, C++-классы или исходный AnimBP с
RogueAnimInstance. Удаление локальных ассетов не требуется для работы базового примера.


Текущий AnimGraph покрывает наземное движение, атаку и смерть. Полная анимационная
машина состояний исходного курса, включая отдельные состояния прыжка, пока не
перенесена. Для смерти создаётся локальный `AM_Death` с совместимым слотом и
удержанием последней позы; исходная анимация курса не изменяется.
